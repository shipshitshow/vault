# Description

In this video, we test Paperclip, the open source orchestration tool for building zero-employee companies. We set up a full AI team (CEO, CTO, engineers, QA) and tasked them with building an open source Sora alternative from scratch.

We walk through what Paperclip is and how it works, live onboarding and setting up your first AI agents, hiring AI engineers and delegating architecture decisions, watching AI agents build an MVP in real time, token usage and cost breakdown, and our honest first impressions.
