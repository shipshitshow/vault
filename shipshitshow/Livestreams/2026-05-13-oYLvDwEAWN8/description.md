Anthropic developer Derek wrote about it last week. Stop using Markdown files for planning output. Use HTML instead.

So we tested it live. Side by side. Same plan, same prompt, both formats. Here's what actually happened.

HTML plans are 63% more token expensive than Markdown. The output is prettier, more visual, easier to share, and you can embed previews, color palettes, and interactive elements directly in the plan. Markdown is leaner, faster, cheaper, and Claude actually prefers it for internal planning based on signal to noise ratio.

The real answer: use both depending on context. Internal planning and optimization, use Markdown. Sharing with stakeholders, visualizing components, or building a brand document, use HTML.

We also built a live demo: a micro app to check open source repositories for vulnerability based on the recent ten stack package attack. Full plan in both formats, token count compared, Claude picks the winner.
