## Source and maintenance

This vault owns identity and tokens. [Public skills](https://github.com/shipshitshow/skills) own `profiles/shipshitshow.md` and synchronized bundles. [The show application](https://github.com/shipshitshow/show.shipshit.dev) consumes those contracts and generates its shared web tokens from this kit. Update source, synchronize, and run drift checks together. See [production handoff](production.md#repository-handoff).

Only guides and standalone marks are distributed in this public kit. Original portraits, character grids and face-containing working boards remain private. Separately approved finished website exports live in the application that serves them. Inventory statuses distinguish current exports from archived exploration; an asset’s presence is not approval for a new destination.
