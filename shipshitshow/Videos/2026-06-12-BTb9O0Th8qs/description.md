Claude Fable 5 launched, so we tested it the obvious way: can it help build an AI-native game studio?

Last week we built a browser FPS with Opus 4.8 in one prompt. This time we pushed the idea further: multiple game prototypes, shared lore, reusable systems, sprites, agents, automation loops, and one repo acting like a tiny AI game studio.

This is not just “AI made a game.” The interesting part is the production loop around it:
- multiple game ideas in one shared universe
- FPS, tower defense, runner, RPG/fighting-style experiments
- lore stored like an Obsidian vault
- reusable systems for sprites, rules, animation, and gameplay
- agents that keep context across the whole project
- a public repo people can inspect and build on

The real question is not whether Claude Fable 5 can make a cool demo. 
The question is whether AI can turn one idea into a repeatable game production pipeline.

If you build games, software, agents, or weird AI-native products, this is where it gets interesting.
