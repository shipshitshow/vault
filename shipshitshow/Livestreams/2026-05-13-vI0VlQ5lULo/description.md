We have been using markdown for every Claude plan, spec, and code review for 3 years.

This week an Anthropic engineer said to stop.

He switched his entire workflow to HTML output. Karpathy cosigned. Addy Osmani from Google agreed.

So we are testing it live.

HTML output from Claude is richer, more readable, instantly shareable, and interactive. Markdown made sense when tokens were expensive. Context windows are now 1 million tokens. The default never got updated.
