### Decisions

1. **60-min show format**: 30 min news (3x10 min) + 25 min demo + 5 min wrap
2. **No intro fluff**: Cold open, straight to content
3. **CLI over web UI**: Prompt-based thumbnail generation via command line
4. **Thumbnails in episode folder**: Saved alongside content, not separate directory
5. **GenFeed.ai integration**: Use existing API, not build new backend

### Patterns Established

- Episode folders: `YYYY-MM-DD-slug/`
- Episode ID format: `sss-XXX`
- Frontmatter includes `news` and `demo` sections
- Prompt templates use Handlebars syntax `{{variable}}`
